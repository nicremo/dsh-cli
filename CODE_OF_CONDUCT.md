# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and keep discussions about the work. Harassment, insults and personal attacks are not tolerated.

Report unacceptable behaviour through GitHub's private vulnerability reporting (Security tab) or by contacting the maintainer through their GitHub profile. Reports are handled confidentially.
